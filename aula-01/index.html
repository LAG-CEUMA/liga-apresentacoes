PRÁTICA · O CONCEITO

Git em três palavras

Repository

a pasta do projeto, com todo o histórico

Commit

uma foto do projeto, com um nome

Push

envia as fotos para o GitHub

É como o histórico do Google Docs, só que você escolhe quando salvar.

PRÁTICA · PRIMEIRO COMMIT

Seu primeiro commit

1

Repository > Show in Explorer e abra semana-01/ENTREGA.md

2

Preencha as 3 linhas e salve com Ctrl+S

3

Volte ao GitHub Desktop: a mudança aparece na lista

4

Summary: Preenche entrega da semana 1

5

Clique em Commit to main

6

Clique em Push origin

7

Abra o github.com e confira que o arquivo mudou
